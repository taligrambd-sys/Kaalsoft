Webkaal is a powerful and versatile HTML-to-APK conversion platform designed to seamlessly transform web applications, HTML5 games, and websites into fully functional, high-performance native Android applications. Equipped with an advanced JavaScript bridge, Webkaal enables smooth web-to-native interaction, allowing developers to easily integrate features like native Unity Ads monetization (supporting Banner, Interstitial, and Rewarded ad placements), custom splash screens, offline support, file downloading, and dynamic digital signature key (keystore) configuration. Built with modern Android standards and optimized for speed and light package sizes, Webkaal empowers creators and web developers to package, monetize, and publish their web content to Android devices effortlessly.

Webkaal Unity Ads Integration Overview: This application features a built-in native Android-to-JavaScript bridge for Unity Ads SDK v4.12.0. It allows web applications running inside the WebView to initialize Unity Ads, request banner placement positioning, load and display Interstitial and Rewarded ads, and listen for real-time lifecycle callbacks directly via JavaScript context.

1. Registered JS Bridge Namespaces

You can invoke Unity Ads methods using any of the following global JavaScript interface objects: window.Android, window.UnityAds, window.UnityAdsAndroid, window.UnityAdsBridge, or window.HTMLToAPK.

2. Available Methods & Functions

The native bridge exposes the following methods for complete ad management:

  • initUnityAds(gameId, testMode): Manually initializes Unity Ads with your Game ID and boolean test mode flag.
  • isUnityAdsInitialized() / isInitialized(): Returns true if the Unity Ads SDK is initialized and ready.
  • setBannerPosition('TOP' | 'BOTTOM'): Sets the anchor alignment for the banner container.
  • loadBanner('Placement_ID') / loadBannerAd('Placement_ID'): Fetches and displays a banner ad.
  • hideBanner() / removeBanner(): Hides and cleans up the active banner ad view.
  • loadInterstitial('Placement_ID') / loadInterstitialAd('Placement_ID'): Preloads full-screen Interstitial ad.
  • showInterstitial('Placement_ID') / showInterstitialAd('Placement_ID'): Displays the preloaded Interstitial ad.
  • loadRewarded('Placement_ID') / loadRewardedAd('Placement_ID'): Preloads Rewarded video ad.
  • showRewarded('Placement_ID') / showRewardedAd('Placement_ID'): Displays the preloaded Rewarded video ad.

3. Supported Window Event Callbacks

Define any of these functions in your web page's global scope (window) to automatically receive real-time event updates from native Android:

  • onUnityAdsInitialized() & onUnityAdsInitFailed(errorMessage)
  • onBannerLoaded(placementId) & onBannerFailed(placementId, error)
  • onInterstitialLoaded(placementId) & onInterstitialFailed(placementId, error)
  • onInterstitialShowStart(placementId), onInterstitialShowFailed(placementId, error), onInterstitialClicked(placementId), & onInterstitialClosed(placementId)
  • onRewardedLoaded(placementId) & onRewardedFailed(placementId, error)
  • onRewardedShowStart(placementId), onRewardedShowFailed(placementId, error), onRewardedClicked(placementId), onRewardedClosed(placementId), & onRewardedCompleted(placementId)

অ্যাপে যুক্ত করা Unity Ads JavaScript Bridge (window.Android, window.UnityAds, window.UnityAdsAndroid, window.UnityAdsBridge, window.HTMLToAPK) দিয়ে আপনার HTML/JS ওয়েবসাইট থেকে সরাসরি নিচের সমস্ত কাজগুলো করা যাবে:

১. SDK ইনিশিয়ালাইজেশন ও স্ট্যাটাস চেক

  • initUnityAds(gameId, testMode) — ওয়েবসাইট চলাকালীন ডাইনামিক্যালি Unity Game ID এবং Test Mode দিয়ে SDK শুরু করা।
  • isUnityAdsInitialized() — ইউনিটি এডস সক্রিয়/ইনিশিয়ালাইজড আছে কিনা তা true / false রিটার্ন করে জানা।

২. ব্যানার বিজ্ঞাপন (Banner Ads)

  • loadBannerAd("Placement_ID") বা loadBanner("Placement_ID") — নির্দিষ্ট Placement ID দিয়ে ব্যানার লোড ও ডিসপ্লে করা।
  • setBannerPosition("TOP") বা setBannerPosition("BOTTOM") — ব্যানারের অবস্থান স্ক্রিনের উপরে বা নিচে সেট করা।
  • hideBanner() / removeBanner() — ব্যানার অ্যাড স্ক্রিন থেকে সরিয়ে ফেলা।

৩. ইন্টারস্টিশিয়াল অ্যাড (Full-screen Interstitial Ads)

  • loadInterstitialAd("Placement_ID") — ফুলস্ক্রিন বিজ্ঞাপন ব্যাকগ্রাউন্ডে প্রি-লোড করা।
  • showInterstitialAd("Placement_ID") — প্রি-লোড হওয়া ফুলস্ক্রিন বিজ্ঞাপন ব্যবহারকারীকে দেখানো।

৪. রিওয়ার্ডেড ভিডিও অ্যাড (Rewarded Video Ads)

  • loadRewardedAd("Placement_ID") — পুরস্কারভিত্তিক ভিডিও বিজ্ঞাপন প্রি-লোড করা।
  • showRewardedAd("Placement_ID") — রিওয়ার্ডেড বিজ্ঞাপন দেখানো (যেমন: পয়েন্ট বা কয়েন দেওয়ার জন্য)।

৫. অটোমেটিক JavaScript Callbacks (ইভেন্ট পাওয়ার জন্য)

বিজ্ঞাপনের যেকোনো অবস্থার আপডেট ওয়েবসাইট বা HTML-এ পাওয়ার জন্য নিচের গ্লোবাল ফাংশনগুলো ব্যবহার করা যায়: 

// ইনিশিয়ালাইজেশন আপডেট
window.onUnityAdsInitialized = function() { console.log("Unity Ads Ready!"); };

// ইন্টারস্টিশিয়াল ও রিওয়ার্ডেড লোড / শোর আপডেট
window.onInterstitialLoaded = function(placementId) { ... };
window.onInterstitialShowStart = function(placementId) { ... };
window.onInterstitialComplete = function(placementId) { ... };

window.onRewardedLoaded = function(placementId) { ... };
window.onRewardedComplete = function(placementId) { 
    // ব্যবহারকারীকে পয়েন্ট বা রিওয়ার্ড দেওয়ার কোড
};

// ব্যানার ইভেন্ট
window.onBannerLoaded = function() { ... };
window.onBannerFailed = function(error) { ... };
